Never create layouts that look AI-generated.

Avoid:

Centered everything

Repeating card grids

Too many gradients

Huge glassmorphism everywhere

Equal spacing in every section

Generic illustrations

Random icons

Random blobs

Random floating circles

Instead:

Create visual hierarchy.

Alternate layouts.

Mix left-right composition.

Use negative space.

Design like Stripe.

Design like Linear.

Design like Vercel.

Inspired only.

Never copy.

Every section must answer:

Why does this section exist?

What action should the user take?

What is the visual focus?

Never create sections only because they are common in portfolio templates.

Every section must have a unique layout and clear purpose.

If two sections look visually similar, redesign one of them.
